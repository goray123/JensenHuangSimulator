소유권 분쟁 — 가정용 로우폴리 아이템 23종

실행
1. ZIP을 새 폴더에 풀고 project.godot을 Godot에서 가져옵니다.
2. F5로 아이템 뷰어를 엽니다.
3. Previous / Next 또는 좌우 방향키로 물건을 바꿉니다.
4. 드래그로 360도 회전, 휠로 확대/축소, Space로 자동 회전, R로 초기화합니다.

기존 게임에 적용
- assets/scenes/에서 원하는 .tscn을 프로젝트로 복사해 인스턴스로 추가합니다.
- 각 .tscn은 메시·재질·충돌체가 내장된 독립 파일입니다. 원본 GLB 없이 사용할 수 있습니다.
- 원래 부품별 형상이 필요하면 assets/glb/의 원본 GLB를 사용합니다.
- 단위는 1m, Y 위, 원점은 바닥 중앙입니다. 뷰어에서만 크기를 보기 좋게 정규화합니다.
- 기존 맵 프로젝트를 수정하거나 아이템을 자동 배치한 패키지는 아닙니다.

씬 구조
RigidBody3D 또는 Area3D
  Visual: 병합 메시 1개 / 표면 1개 / Unshaded 정점색 재질 1개
  Collision: 볼록 충돌 또는 감지 상자
  GripPoint: 집기 기준 Marker3D

물웅덩이·바나나껍질: Area3D, floor_hazard 그룹.
나머지 21개: RigidBody3D, pickup_item 그룹. 기본 freeze=true로 배치 상태를 유지합니다.
던지는 로직을 연결할 때 freeze=false로 전환해 속도/충격을 적용할 수 있습니다.
질량은 모델별 제안 값이며 게임 밸런스 수치로 확정한 값이 아닙니다.
볼록 충돌은 투척용 근사 형상이며 반지/프라이팬/옷의 구멍까지 따라가지 않습니다.

물리 레이어
1 World / 2 Players / 3 Items / 4 Hazards.
물건: 레이어 값 4, 마스크 7. 함정: 레이어 값 8, 마스크 2.
기존 프로젝트에 맞춰 레이어와 마스크를 바꿀 수 있습니다.

용도 정보
item_id, display_name, room, gameplay_note를 루트 메타데이터로 저장했습니다.
data/item_manifest.json에도 목록·크기·삼각형·질량 제안·사용자 효과 아이디어가 있습니다.
바나나 지뢰화, 미끄러짐, 케이크/계란 화면 가리기, 랜덤 돈, 가짜 반지,
편지 결산 이벤트, 코트 방어, 독 피해/구토는 연결할 게임 규칙 메모입니다.
해당 전투/화면/시나리오 효과 코드는 이 모델 패키지에 구현하지 않았습니다.

검증
Godot 4.7.2 Compatibility에서 23개 씬을 로드하고 실제로 렌더했습니다.
전체 4,434 삼각형. 원본 표면 799개를 23개로 병합. 원본 경계 오차 최대 약 2.98e-8m.
21개 RigidBody 충돌, 2개 Area 감지, 낙하 후 바닥 안착, 뷰어 전환/회전 검사 통과.
reports/에 실제 엔진 렌더와 검사 JSON을 포함했습니다.

원본

23개 AI 회전 참고 시트, 23개 실제 Blender 회전 렌더, 생성 프롬프트와 재생성 코드가 있습니다.
